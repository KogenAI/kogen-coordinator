# Reject tabs in YAML node indentation

Slug: yaml-tab-indentation-rejection
Model: not applicable — this is a stateless parsing validation change
Acceptance:
- .kogen/intents/yaml-tab-indentation-rejection/acceptance.feature
- features/steps/yaml-tab-indentation-rejection__parse.js
- features/steps/yaml-tab-indentation-rejection__driver/main.go

Reject tabs used before a YAML node as invalid indentation, returning a parse problem that names the offending source line. Replace silent removal of indentation tabs, not the accepted space indentation rules or scalar contents. Implementation scope is project/yaml.go and project/yaml_test.go, plus regeneration of directly affected recorded results in project/testdata/golden.json as specified in Decision D4; acceptance artifacts exercise the parser through ParseConfig without changing that interface.

- Keep accepted space indentation and scalar contents unchanged; restrict implementation edits to project/yaml.go and project/yaml_test.go except for the narrowly scoped golden regeneration in Decision D4.
